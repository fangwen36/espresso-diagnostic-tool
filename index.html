📐 流速测算原理（达西定律）

本诊断仪底层的流体物理引擎基于多孔介质流体力学的达西定律建立：

F(t) = P(t) / R(t) (g/s)

F(t) = 实时流速 · P(t) = 实时压力差 (bar) · R(t) = 粉饼实时流阻

流阻 R(t) 的动态演变受控于：
1. 基准阻力： 研磨细度和粉量决定。
2. 物理通道崩塌： 当压力超过粉床剪切击穿上限时，粉床撕裂穿孔。
3. 溶解性冲刷衰减： 可溶物随萃取进行减少，流阻自然递减。

🔍 诊断判定逻辑

系统根据手绘压力曲线（或感官选择题映射的拟合曲线），结合粉量、液重、粉碗类型和机器类型，通过达西定律反推实时流速曲线，再基于压力峰值、流速变化趋势、通道崩溃检测等指标，自动匹配对应的物理故障类型。

判定规则：
压力过低 + 流速过高 → 粗研磨/低粉量
压力过高 + 流速过低 → 细研磨/憋压
压力中段骤跌 + 流速暴增 → 通道效应
压力峰值在粉碗对应区间 + 流速平稳 → 正常萃取
