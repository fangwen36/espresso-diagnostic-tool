# Espresso 萃取物理诊断仪

**中文 | [English](README.en.md)**

一个纯前端的意式浓缩萃取物理模拟与诊断工具。通过手绘压力曲线或感官描述输入，基于达西定律的多孔介质流体力学模型，反推实时流速、风味析出，并给出针对性的萃取纠错处方。

## 功能特性

- **双模式输入** — 支持直接在 Canvas 上手绘压力曲线，或通过感官选择题（油脂/颜色/水流/味道）描述萃取现象
- **物理引擎反推** — 基于达西定律与粉饼抗剪强度模型，从压力曲线动态演算实时流速和杯中风味
- **多设备适配** — 支持活塞拉杆机与电泵咖啡机两种机型
- **粉碗选择** — 传统粉碗、快速高流粉碗、增压粉碗三种类型，自动调整判定阈値
- **通道效应检测** — 自动识别粉床通道击穿、抗剪失效、研磨偏粗/偏细等典型萃取故障
- **风味可视化** — 酸/甜/苦风味占比条实时展示
- **诊断处方** — 基于物理特征输出纠错建议，覆盖粉量、研磨度、压粉、拉杆操作等维度
- **移动端适配** — 支持触屏拖拽绘线，响应式布局

## 快速使用

直接打开 `coffee_sim.html` 即可运行，无需任何服务器或依赖：

```bash
open index.html
```

1. **步骤 ① — 状态输入**：选择咖啡机类型和粉碗，调节粉量/液重/时长参数，用手绘曲线或感官选择题描述萃取特征
2. **步骤 ② — 诊断建议**：点击"开始分析"，系统基于物理引擎反推流速曲线、风味占比并输出诊断书
3. **调节参数重试**：点击"重新诊断"返回输入页，调整参数后再次分析

## 物理模型

本工具的流体模拟基于多孔介质流体力学的 **达西定律（Darcy's Law）**：

$$F(t) = \frac{P(t)}{R(t)}$$

- **$F(t)$** — 实时流速 (g/s)
- **$P(t)$** — 实时压力差 (bar)
- **$R(t)$** — 粉饼实时流阻

流阻 $R(t)$ 的动态演变受控于三个因素：

1. **基准阻力** — 由研磨细度和粉量决定
2. **物理通道崩塌** — 当压力超过粉床剪切击穿上限 ($P_{rupture}$) 时，粉床撕裂穿孔，流阻骤降
3. **溶解性冲刷衰减** — 可溶物随萃取进行而减少，流阻自然递减

### 诊断判定逻辑

| 现象 | 诊断 | 建议 |
|------|------|------|
| 压力过低 + 流速过高 | 粗研磨 / 低粉量 | 磨细 2-3 格，增加粉量 |
| 压力过高 + 流速过低 | 细研磨 / 憋压 | 磨粗 1-2 格，减少粉量 |
| 压力中段骤跌 + 流速暴增 | 通道效应 | WDT 布粉针 + 水平压粉 |
| 压力峰值在粉碗对应区间 | 正常萃取 | 保持当前配置 |

## 关于

本项目是一个咖啡萃取领域的交互式物理模拟诊断工具，旨在帮助咖啡爱好者和专业咖啡师通过可视化的方式理解萃取过程中的流体力学原理，快速定位萃取缺陷并找到改进方向。
